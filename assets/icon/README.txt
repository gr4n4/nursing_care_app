앱 아이콘 넣는 곳
==================

1. 이 폴더(assets/icon/)에 아이콘 그림을 아래 이름으로 넣으세요:

      app_icon.png

   - 정사각형 PNG
   - 권장 크기: 1024 x 1024 픽셀
   - 배경이 투명하지 않은(꽉 찬) 그림 권장 (iOS는 투명 배경 아이콘을 허용하지 않음)

2. 그림을 넣은 뒤, 프로젝트 폴더에서 아래 명령을 한 번 실행하세요:

      dart run flutter_launcher_icons

   -> 안드로이드/iOS의 모든 크기 아이콘이 자동으로 생성됩니다.

3. 앱을 다시 빌드/실행하면 새 아이콘이 적용됩니다.
   (홈 화면에 이미 깔려 있으면, 앱을 삭제 후 다시 설치해야 새 아이콘이 보일 수 있습니다.)

설정 위치: pubspec.yaml 의 flutter_launcher_icons: 항목
